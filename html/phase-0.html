Decisions

P0-D1Generous read limits, strict limits on paid endpoints
Chose
Anonymous reads 2000/hour, signed-in users 5000/hour, and AI generation 10/hour per visitor (DRF ScopedRateThrottle, scope ai_generate). Each can be changed with an environment variable (THROTTLE_ANON, THROTTLE_USER, THROTTLE_AI_GENERATE).
Why
With the new 5-minute polling, a dashboard tab makes about 50 requests an hour, so 2000 leaves room for many tabs behind one shared IP (office, mobile carrier). The limit exists to stop abuse, not normal use.
Caveat
Counters live in per-Lambda-container memory (there's no Redis), so the limits are approximate. That's fine for this purpose. The daily AI cap below is exact because it counts database rows.
P0-D2Poll every 5 minutes; load AI analyses on demand
Chose
Live matches, today's matches and upcoming matches refresh every 5 minutes instead of every 15/30/60 seconds. Daily picks and predictions were already on 5 minutes. Each prediction card looks up its saved AI analysis only when opened.
Why
The backend only changes data once a day, and nothing sets matches to "live" (DATA-05), so faster polling fetched identical data. That was roughly 330 requests an hour per tab, which caused the 429 errors. The per-card lookups were one extra request per card on every page load.
P0-D3AI generation stays public, but can't run up a bill
Chose
Three guards on POST /ai-recommendations/generate/. (1) If an analysis for that prediction completed within the last AI_REUSE_HOURS (6), return it instead of calling the LLM again; the response includes "reused": true. (2) Stop at AI_DAILY_GENERATION_LIMIT (200) new analyses per UTC day across all visitors, returning HTTP 429 with a readable message. (3) The per-visitor 10/hour limit from P0-D1.
Why not admin-only
The AI button is a visitor-facing feature. Making it admin-only would remove it from the product. The worst case is now 200 LLM calls a day. Also set a monthly spend limit on the OpenRouter key itself as a second line of defence.
P0-D4Documents, search and on-demand model runs become admin-only
Chose
Documents: list, retrieve and stats stay public. Create, update, delete, upload, embed, refresh, scrape-news and search now need a staff token. Predictions: generate and batch are admin-only.
Why
Documents feed the AI prompt, so anonymous edits were a way to inject instructions into it. Search, embed and scrape spend API money. I checked the frontend: none of these endpoints is called by any page, so no visitor feature changes.
P0-D5Remove --clear from the admin task runner
Why
sync_real_data --clear deletes every league, team, match, odds row and prediction. generate_predictions --clear deletes all predictions. That shouldn't be one API call away. The CLI still accepts --clear for deliberate use.
P0-D6Admin: fix Sync, disable Train, show errors
Chose
Sync Data now sends --fixtures-only (fixtures + recent results + predict + validate), the same as the daily schedule. Train Model is disabled, with a visible reason, until Phase 3 adds the "new model must beat the current one" check. Trigger failures show on the page. An expired or invalid token (401/403) sends you back to the sign-in form with "Your session expired".
Why
--fixtures re-imported every historical season first and always ran past 15 minutes. The Train button trained on one league and put that model live for all 20 (ML-04). The daily scheduled training is unchanged.
P0-D7Help page tells the truth
Changed
Accuracy: "87% / 95%+" became the measured ~49–50%, next to the bookmaker-favourite baseline (~50–54%). Data sources: removed "Understat xG" and "real-time odds", which aren't connected. Leagues: says which 8 get new data. Update frequency: daily sync and retrain, no live scores. The feature card no longer says "high accuracy", and the Value Bets card explains that it needs odds.
P0-D8ECR: keep the newest 5 images; logs: keep 14 days
Checked first
Both Lambdas run digest sha256:eb0ea0e2…, which is the newest image (75165fd). A preview of the rule showed it expires exactly the 7 oldest (4c89fde, 77ec9c1, 8d38c3a, 9739f47, 9763253, aa321ae, e72d22c), about 9.2 GB. ECR deletes them within 24 hours. Any of them can be rebuilt from its git commit.
Watch
Keep the image the Lambdas actually run among the newest 5. After a deploy it always is. Don't push more than 4 test builds without deploying one.
Logs
14 days on bet-hope-web, bet-hope-manage, bet-hope-infra-toggle and the leftover bet-hope-ml-tasks. The apps logger now defaults to INFO in production (APPS_LOG_LEVEL).
